# PhotoName — 给摄影师的文件整理工具

> 一句话：**在你的照片进入 Lightroom / NAS 之前，把它们安全、批量地整理成有意义的名字。**

---

## 你是不是也遇到过

拍完一次活动，卡里是这样：

```
DSC_8231.ARW
DSC_8231.JPG
DSC_8231.XMP
DJI_0381.DNG
IMG_4821.HEIC
```

- 半年后根本不知道哪张是哪天、哪台相机拍的
- RAW、JPEG、XMP 是同一张照片，却要当成三个文件管理，改个名字就怕改散了
- 两台相机时钟差几秒，按时间排顺序全乱
- 想批量改名，又怕 3000 个文件里出一个覆盖、漏改，风险太大

---

## PhotoName 做什么

把你的素材当成**「一张照片」**而不是「一堆文件」来整理：

1. **选个文件夹**（SD 卡 / SSD / 本地目录）
2. **自动识别成组** — RAW + JPEG + XMP 自动配对成同一张照片
3. **按真实拍摄时间排序** — 直接读照片里的拍摄时间，不用看文件名
4. **你定一个命名规则** — 比如 `20260902_Tokyo_0001`，或者 `婚礼_A7R5_0001`
5. **改名前先预览、先体检** — 冲突检查、重名检查、缺 XMP 提醒，有风险就告诉你
6. **批量改名，随时撤销** — 每一步都有记录，改错了能一键还原

结果：

```
DSC_8231.ARW  →  20260902_Tokyo_0001.ARW
DSC_8231.JPG  →  20260902_Tokyo_0001.JPG
DSC_8231.XMP  →  20260902_Tokyo_0001.XMP
```

组永远不散，随时可回退。

---

## 三条底线

- **绝不覆盖**：宁可不动手，也不改错你的照片
- **永远可撤销**：每次改名都有日志，Undo 是基本功能，不是高级功能
- **照片不出你的电脑**：无账号、无登录、不上传，所有处理都在本地完成

---

## 形态与价格

- macOS 优先，iPad 版本支持「现场整理：读卡器 → iPad → 移动硬盘」
- 免费版可用完整流程，单次限 100 张照片
- Pro 一次性买断（约 $10），不限张数 + 自定义模板 + 多机位功能，**无订阅**
